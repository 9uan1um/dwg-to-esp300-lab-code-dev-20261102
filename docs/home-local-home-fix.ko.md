# Home 이후 Local home 복귀 정지 문제 수정

2026-10-28, 개발 폴더 `dwg-to-esp300-lab-code-dev-20261028`에서 수정·검증했다. 원본 프로그램 소스는 변경하지 않았다. 사용자의 추가 승인에 따라 원본 8768 웹앱은 연결 해제 후 종료하고, 개발본을 8773에서 실제 ESP300에 연결했다.

## 확인한 결함과 수정

1. **서버의 좌표 기준 관리:** `Home`이 이동 명령을 보낸 뒤 `home_ref`와 이동 범위 중심을 `(0,0,0)`으로 덮어쓰고 초점 보정도 초기화했다. 따라서 `Set local home`으로 등록한 복귀 지점을 잃었다. 수정 후 Home은 현재 좌표계의 `(0,0,0)`으로 이동만 하며, 등록 기준·좌표 변환·범위 중심·초점 기준을 보존한다.
2. **서버의 수동 이동 완료 판정:** 목표와 실제 좌표가 다르거나 MD 응답을 확인하지 못하면 `_manual_target_raw`가 무기한 남았다. 웹앱은 이 상태를 계속 이동 중으로 해석하여 Home·복귀·Run 등을 막았다. 명령 미수행 및 잘못된 MD 응답을 모의 제어기에 주입하여 재현했다. 당시 사용자의 개별 고장에 어떤 제어기 응답이 발생했는지는 그 시점의 기록이 없어 단정하지 않는다.
3. **오류 처리:** 정상 도착은 실제 TP와 세 축 MD로 확인한다. 세 축이 멈췄지만 목표에 도달하지 못한 상태가 유지되면 실패를 표시하고 대기를 끝낸다. 이동 완료 확인 시간이 초과되면 ST로 정지를 요청한다. 정지 확인도 실패하면 연결을 해제하고 명시적인 오류를 표시하며, 자동으로 정상 완료 처리하거나 재연결하지 않는다. 정상적인 복구 이동이 성공하기 전에는 Run을 차단한다.
4. **중복 명령:** 이미 동일한 Home/Local home 위치에서 정지한 경우 불필요한 PA를 보내지 않는다. 요청 생략 판정은 0.02 mm 도착 허용오차와 분리했다. 따라서 0.01 mm 떨어진 위치에서도 실제 복귀 명령을 보낸다. 1e-6 mm 비교 기준은 소프트웨어 요청 비교용이며 장비 정밀도 보장이 아니다.
5. **화면:** 등록한 Local home 좌표, 수동 이동 중 상태, 수동 이동 실패 이유를 Jog 패널에 표시한다. Home 확인창은 등록 기준을 유지한다는 점을 설명한다.
