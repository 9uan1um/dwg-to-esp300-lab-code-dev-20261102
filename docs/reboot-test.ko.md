# 재부팅 후 실행 테스트

아직 게시하기 전의 확인 절차입니다. 소프트웨어 실행 검증은 끝났으며, 아래 재부팅·실물 연결 테스트는 사용자가 진행합니다.

## 실행할 파일

현재 작업 폴더는 `C:\Users\YOUR_USER\Projects\FLW\dwg-to-esp300-lab-code`입니다.

- 현재 폴더에서 테스트: `dwg-esp300-launch.cmd` 더블클릭.
- 배포본 자체 테스트(권장): `dist\FLW-ESP300-Windows-x64.zip`을 **새 폴더에 모두 압축 해제**하고, 그 안의 `FLW-ESP300\dwg-esp300-launch.cmd` 더블클릭. ZIP 안에서 바로 실행하지 않습니다.

기존에 설치한 Conda를 활성화하거나 프로그램을 다시 설치할 필요는 없습니다. ZIP에는 `runtime/`이 포함되어 있으므로 실행 중 인터넷도 필요하지 않습니다.

## 1. 전원을 껐다 켠 후 앱 실행

1. Windows에 로그인합니다. ESP300 전원을 켜고 RS-232/USB 케이블을 연결합니다.
2. 위 CMD 파일을 실행합니다. 우선 WSL 브리지는 실행하지 않습니다.
3. 브라우저에서 `http://127.0.0.1:8768`이 열리고 샘플 도면이 표시되는지 확인합니다. CMD 창은 열어 둡니다.

앱 화면이 열리는 것과 ESP300 연결 성공은 서로 다른 확인 단계입니다.

## 2. Windows 직접 연결 확인

1. Jog → Manual jog (ESP300)에서 **Find Windows ports**를 누릅니다.
2. **Windows COM ports**에서 해당 어댑터를 선택합니다. Port 칸과 Baud `19200`을 확인합니다.
3. **Test hardware link (no motion)**을 누릅니다. 이 검사는 Dry run 체크 상태와 관계없이 실제 제어기에 버전 조회만 하며, 모터를 켜거나 축을 움직이지 않습니다.
4. 실제 ESP300 버전 응답이 표시되면 Windows 직접 연결 성공입니다. 이 경우 WSL은 필요 없습니다.

COM 번호가 목록에 뜨는 것만으로 성공으로 판단하지 않습니다. 포트 열기 오류·응답 없음이 발생하면 오류를 확인하고 아래 WSL 경로를 선택할 수 있습니다.

## 3. 필요한 경우에만 WSL 연결 확인

현재 PC에 준비된 전용 WSL 환경을 사용하는 경로입니다. WSL 설치가 불가능한 다른 PC에는 요구하지 않습니다.

1. 실행한 폴더의 `esp300-bridge.cmd`를 별도 창에서 실행합니다. `Listening` 표시까지 기다리고 창을 열어 둡니다. 처음 공유하는 USB 단자는 관리자 승인 창이 나타날 수 있습니다.
2. 앱에서 **Use WSL (optional)**을 누릅니다.
3. 주소 `rfc2217://127.0.0.1:22170`, Baud `19200`을 확인합니다.
4. **Test hardware link (no motion)**으로 실제 버전 응답을 확인합니다.

`Listening`은 브리지 준비 완료이며, 실제 버전 응답까지 받아야 장비 연결 성공입니다. 설치가 완료된 이 PC에서는 WSL 설치 스크립트를 다시 실행할 필요가 없습니다. USB가 WSL에 연결된 동안에는 같은 어댑터를 Windows COM에서 동시에 사용하지 않습니다.

## 4. 화면 기능과 종료 확인

- **카메라:** Focus camera에서 Index를 확인하고 Connect합니다. 이 PC의 기존 외부 카메라 인덱스는 2였지만 재연결 후 달라질 수 있습니다.
- **도면:** 기본 샘플과 본인의 DWG/DXF를 열고 미리보기·코드 다운로드를 확인합니다.
- **Dry run:** Dry run 체크를 유지하고 Connect하면 실물 장비 없이 조작을 확인할 수 있습니다. Dry run 연결은 실물 연결 성공의 증거가 아닙니다.
- **실제 이동:** 버전 검사 후 실제 제어가 필요할 때만 Dry run을 해제하고 Connect합니다. Live Connect는 모터를 켭니다. 이동 방향·원점·속도·가공 경로는 장비에 맞춰 별도로 확인합니다.
- **종료:** 작업이 멈춘 상태에서 각 CMD 창의 Ctrl+C 또는 `esp300-stop.cmd`로 종료합니다. 브라우저만 닫는 것으로 서버가 종료되지는 않습니다.

## 통과 기준과 오류 기록

앱 실행, 샘플 로딩, 선택한 연결 방식의 실제 버전 응답, 필요한 카메라 영상, 정상 종료를 확인합니다. Windows 직접 연결과 WSL 연결은 대안이므로 둘 다 성공해야 하는 것은 아닙니다.

실패하면 사용한 경로(배포 ZIP/작업 폴더), 실패 단계, CMD 또는 화면의 오류 문구를 기록합니다. 종료·재실행 시 오류 창을 읽기 전에 닫지 않습니다. 장비 없이 파일·의존성만 확인할 때는 해당 폴더의 CMD에서 `dwg-esp300-launch.cmd -Check`를 실행합니다.
