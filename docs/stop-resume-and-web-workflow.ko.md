# Stop/Resume 및 브라우저 작업 흐름 검증 — 2026-10-28

최종 결과: 브라우저로 실제 Blade 도면 연속 2회, 각각 526/526구간 완료. 이어 최종 배포 버전에서 실제 X축 짧은 왕복 작업을 Stop/Resume하여 6/6구간 완료했다. 자동 초점의 광학 품질, 실제 레이저 가공, 빨간 STOP의 실제 하중 유지, 다운로드는 별도 미검증 항목이다.

## 검증 기준과 조작 방법

정상 사용자가 `http://127.0.0.1:8768/` 웹앱으로 준비·시작·상태 확인·정지·재개·다음 실행을 할 수 있어야 한다. 최종 도면 시험의 시작은 실제 브라우저의 **Run on machine → 실제 장비 시작** 버튼으로 한다. 동일 도면을 겹쳐 하나의 작업으로 만든 시험이 아니다. 1회 완료 후 같은 페이지에서 다시 버튼을 눌러 별도 작업 ID로 2회를 시작한다. 두 회 사이에는 Home, Go to local home, Center, 재연결, 새로고침을 하지 않는다.

별도 Python 관찰기는 `/api/jog/status`, `/api/run/status`, `/api/run/records`를 읽어 기록할 뿐 모터 명령을 보내지 않는다. 완료 후 진단은 `/api/jog/diag`의 읽기 명령으로 MD/MO/TP/TB를 대조한다. 기록 API 호출은 브라우저 조작을 대신한 실행이 아니다.

레이저 OFF, 경로 확보는 사용자 확인 조건이다. 이번 시험의 초점은 사용자가 요청한 대로 Center → Set local home으로 대체했다. 광학적 초점 품질이나 레이저 가공 결과를 검증하지 않는다. ESP300의 TP/MD는 제어기 읽기 결과이며 별도 변위계로 측정한 위치 정확도·반복정밀도가 아니다.

## 장비를 움직이지 않는 브라우저 검사

별도 `127.0.0.1:8772`는 실제 파일·웹앱과 모의 MovingESP를 사용한다. 실제 시리얼 열기·하드웨어 probe·카메라 연결은 금지했다. LIVE 표시를 가진 실제 실행기 분기를 가짜 제어기로 검사하므로 이 포트의 결과를 실기 결과로 세지 않는다.

- Line/Rect/Circle/Spiral 생성, Blank, All/None, pass=2 Apply, Delete selected 확인.
- preview 재생·일시정지·scrubber=500·Restart 확인. 예상 시간과 계획 진행률 변경 확인.
- Sample의 0.5배 배율, 수동 중심 시작 직선의 2배 배율 적용 확인.
- 파일 선택 → Open file로 DWG 업로드·읽기, Clear로 파일 선택 해제, Open path로 같은 서버 원본 재읽기, All entities·90도 회전 결과 확인. All entities는 치수·주석 등도 포함해 452경로이므로 이번 실기용 11경로와 다르다. 452경로는 실제 기계로 실행하지 않았다.

## 기록의 해석과 남은 한계

`상세 구간 기록 (진단용)`을 켰을 때만 구간 이벤트를 메모리 버퍼에 남긴다. 이번 시험은 관찰기가 디스크에 별도 보존했다. 시작·완료 목표, 읽기 위치, stop 요청/확정, resume, run_end를 작업별로 남겨 오류 해결과 정상 작동 확인에 사용한다. 평상시 기록을 강제하지 않는다.

관찰기의 jog와 run GET은 서로 다른 시각의 조회다. 한 샘플의 위치와 index를 원자적 측정처럼 비교하면 안 된다. 중단점은 stop_confirmed 이벤트와 정지 후 독립 진단을 기준으로 한다. 종료 직후 마지막 TP와 후속 TP가 미세하게 달라질 수 있으므로 MD·허용오차 판정 및 후속 정지 위치를 함께 본다.

이번 자동 도착 허용오차는 0.02 mm다. 검증은 제어기의 이동 완료 및 구간 순서 검증이며, 목표 도달 정밀도가 20 µm로 보장된다는 뜻이 아니다. 수백 구간의 개별 PA 명령과 정지 확인은 연속 보간 가공의 일정 속도·궤적 품질을 보장하지 않는다. 실제 elapsed와 계획 시간은 직렬 통신·가감속·정지 확인 오버헤드 때문에 다를 수 있다.

1회차의 cut 492구간은 계획 573.042초, 관찰 833.078초였다. 원형 경로에 해당하는 92구간 단위 작업은 Z/초기 이동을 포함해 계획 약 21.5~24.6초, 실제 약 69.9~74.0초였다. 따라서 nominal cut 0.4 mm/s 입력을 곡선 전체의 일정 가공 속도로 해석하면 안 된다. 레이저를 켜고 가공할 때 구간 정지·대기 동안의 노광 영향은 이번 레이저 OFF 시험으로 검증하지 않았다. 계획/실제 시간을 구분해 표시하는 이유다.

브라우저 Download code는 이번 세션의 다운로드 거부로 끝까지 검증하지 않았다. 우회하여 내려받지 않았다. 자동 초점 scan·active tracking·spiral survey의 실제 광학 결과는 이번 '초점이 맞춰진 것으로 가정'한 동작 시험에 포함하지 않았다. 빨간 STOP의 실제 하중 유지·정지 거리·안전 등급도 확인하지 않았다. 따라서 이번 결과만으로 모든 기능 또는 공장 투입 적합성을 포괄 승인하면 안 된다.

특히 Center 도중 빨간 STOP 코드가 추가 MF를 생략하더라도, AB 자체가 ZE 설정의 영향을 받으므로 수직축 유지 전원을 보장하지 않는다. 이 동작은 일반 Stop run(ST) 시험과 다르다. 코드의 잘못된 'holding power retained' 주석은 정정했으며 비상정지의 실제 동작 설정을 바꾸지는 않았다.

공장 투입 전 별도 기준은 실제 레이저 인터록·독립 하드웨어 비상정지와 수직축 하중 유지, 통신 상실 시 독립 정지, 가공 궤적·속도·치수·초점의 계측 및 충분한 연속 운전 검증이다. 브라우저 정상 작업 흐름이 성공하는지와 이러한 설비 안전·가공 품질 검증은 별개 항목으로 판정해야 한다.
