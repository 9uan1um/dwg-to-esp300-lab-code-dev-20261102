# 카메라 기반 XYZ 신호 탐색

2026-11-02 개발본에 추가. 미러를 제어하지 않고 시료 스테이지를 움직여 카메라 발광 신호를 찾는다.

## 사용

개발 서버를 다시 시작한 후 카메라와 ESP300을 연결한다. `Scan focus: XY에서 시료 신호 찾기 + Z 초점`을 켜고 현재 위치 기준 XY 각 축의 ±범위와 간격, Z ±범위와 간격을 입력한 다음 `Scan focus`를 누른다. XY 범위는 자동으로 정하지 않는다. Wide/Narrow/Custom 및 Active는 기존 Z 탐색이다.

탐색은 가까운 XY 위치부터 시작한다. 각 위치에서 Z 전 범위를 측정하고, 양쪽에서 내려가는 피크와 주변 신호가 있는 첫 위치를 정밀 탐색한다. 최종 위치에서 재측정한 점수가 후보의 70–130% 범위이면 확정한다. 이 수치는 초기 소프트웨어 판정 기준이며 실험으로 검증한 초점 정확도가 아니다.

전체 예정 이동이 기존 XY 원형 제한과 Z 제한 안에 있는지 먼저 검사한다. 최대 5000개 거친 측정점으로 제한한다. 각 이동은 ESP300 MD/TP 도착 확인 후 새 카메라 프레임 여러 장의 중앙값을 사용한다. XY 좌표계와 Home을 다시 정의하지 않으며 성공 시 Z focus trim만 적용한다.

`Stop XYZ search`는 XYZ 탐색만 중지한다. 중지·신호 없음·실패 시 마지막 위치에 머물며 자동 복귀하지 않는다. 이동 중 정지한 경우 현재 위치 및 수동 이동 오류를 확인해야 한다. 기존 E-STOP도 사용할 수 있다.

## 판정의 한계

현재 카메라의 red-glow/bright-core blob 점수를 사용한다. 시료가 빔을 받아도 카메라에 해당 신호가 나타나지 않으면 찾을 수 없다. 반사광과 실제 가공 발광을 카메라 한 대만으로 확실히 구별하는 기능은 아니다. 영상 중앙과 레이저 위치 사이의 보정도 가정하지 않는다. 설정 간격보다 좁은 신호는 놓칠 수 있고 범위 밖은 탐색하지 않는다. 탐색은 연결된 레이저의 셔터나 출력을 제어하지 않는다.

## 검증

`runtime/python.exe -m unittest test_focus_search test_focus_motion_workflow`

합성 발광 곡선, 위치가 벗어난 시료, 무신호/평탄 신호/끝점 피크/단발 잡음/재측정 실패, 입력 및 이동 범위, 좌표 방향, 도착 확인과 중지를 모의 장비로 검사한다. 실제 카메라와 실제 시료에서의 성공 및 광학 초점 정확도는 별도 확인이 필요하다.
